# TalentoMatch — roadmap

- [ ] Design system (paleta, tipografia, variantes de badge/botão/alerta)
- [ ] Lógica pura: normalização, verificação de evidências, cálculo do percentual, alertas de honestidade (com testes)
- [ ] Função de servidor: validação, limite de uso, chamada única à IA com JSON validado
- [ ] Interface em 3 etapas: Informar, Analisar, Revisar e exportar
- [ ] Exportação PDF com texto selecionável (jsPDF, uma coluna)
- [ ] Privacidade (modal + página) e rodapé
- [ ] Verificações: fluxo fictício completo, validações, clique repetido, edição refletida no PDF, desktop e celular
- [ ] README com problema, especificação, mudanças, evidências reais e limitações
- [ ] Publicação e sincronização com GitHub (ações do usuário no Lovable)
